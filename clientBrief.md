# Solar Battery Group installer scheduler

## Task

Build a micro‑app for the scheduling team.

## Context

The scheduling team books battery installations nationally. The legacy CRM provides limited visibility — it’s unclear which jobs are booked or pending, installer availability is difficult to track, and jobs at risk (e.g. weather) aren’t surfaced. As a result, the team relies heavily on manual workarounds such as spreadsheets.

## Data

Two weeks of jobs (assigned and unassigned), the installer roster, and a data dictionary are included in the attachment.

## Stack

React frontend, Node.js backend, plus any additional technologies of your choice.

## Broad requirements

    UI/UX: Make it as easy and clear as possible for the scheduling team to do their work. What you show and how you show it is up to you.

    Functionality:

        Assign unscheduled jobs to an installer and start time.

        Move scheduled jobs to another time or installer.

        Enforce whatever rules you believe a scheduler app should have.

    Backend:

        A persistent database behind your own API so changes survive refresh and appear across devices.

        At least one live external integration of your choice that adds value for the scheduler.

## Deliverables:

    Link to the GitHub repo

    A deployed link (free tiers are fine). If deployment isn’t possible, a short screen recording is acceptable, though a live link is preferred.

    A short notes file outlining your technical stack
