# SBGScheduler

An installer job scheduler for Solar Battery Group — built as part of an interview take-home.
See [clientBrief.md](./clientBrief.md) for the original client brief.

## Stack

TypeScript throughout. React (Vite) + Material UI frontend, Node.js/Express backend, Prisma ORM over
PostgreSQL (Neon), Open-Meteo for weather + geocoding, deployed to Vercel.
